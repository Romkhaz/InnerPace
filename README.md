# InnerPace

Метроном для бега, который сам подстраивает каденс под пульс.

Задаёте диапазон каденса (например, 180–200 шагов в минуту) и зону пульса
(например, 130–150). Тренировка начинается с нижнего каденса. Пока пульс ниже
целевого (верхняя граница зоны), каденс растёт. Как только пульс уходит выше
цели, каденс снижается, пока пульс не вернётся в зону.

## Два независимых приложения

- **iPhone**: пульс с Polar H10 по Bluetooth, регулятор, метроном в наушники.
  Для пробежек с телефоном. Ремень держит два Bluetooth-подключения, поэтому
  может одновременно быть привязан к часам.
- **Apple Watch**: автономное приложение для пробежек без телефона. Своя
  тренировка HealthKit (пульс с датчика часов или с ремня, привязанного
  к часам, дистанция и темп по GPS, маршрут), тот же регулятор, метроном
  в Bluetooth-наушники, подключённые к часам. Пробежка сохраняется в Здоровье
  и Фитнес как обычная тренировка.
- Между собой приложения не общаются: у каждого свои настройки, друг от друга
  не зависят. Через HealthKit пульс с часов на телефон приходит с задержкой
  в минуты, поэтому такой обмен не используется.

## Экраны на часах

1. Настройка: пульс от и до, каденс от и до, кнопка «Старт». Тонкие параметры
   и звук спрятаны в «Ещё».
2. Тренировка: время, каденс, пульс с цветом зоны и сглаженным значением,
   темп, дистанция. Листается колёсиком, как в стандартной «Тренировке».
3. Управление: стоп и пауза, под ними последнее решение регулятора.

Звук на часах идёт в режиме длительного воспроизведения: при первом старте
watchOS попросит выбрать наушники, и на время пробежки другие приложения
на часах звук не играют.

## Как регулятор принимает решение

1. Пульс сглаживается экспоненциальным фильтром (по умолчанию 10 с).
2. Старт всегда с нижней границы ритма. Регулятор включается, когда пульс
   впервые доходит до нижней границы зоны (`heartRateMin`): сердце вошло
   в рабочий режим, дальше регулятор работает до конца тренировки.
3. Раз в `adjustInterval` секунд (по умолчанию 5) пульс сравнивается с целью:
   - далеко ниже цели: ритм растёт, шаг пропорционален расстоянию,
     максимум `maxStep` (по умолчанию 4);
   - зона подхода за `approachPercent` до цели (по умолчанию 10 %, то есть
     со 135 при цели 150): ритм растёт по одному удару за интервал, чтобы
     инерция пульса не вынесла его за цель;
   - полоса удержания `holdBand` под целью (по умолчанию 8, то есть со 142):
     ритм не растёт;
   - выше цели: ритм падает, в `slowdownFactor` раз быстрее, чем рос
     (от 1 до 10, по умолчанию 3), причём решение принимается по сырому
     пульсу без задержки сглаживания.
4. Основных настроек две: нижняя граница ритма и целевой пульс. Верхняя
   граница ритма считается как нижняя плюс `cadenceSpanPercent` (по умолчанию
   15 %), нижняя граница зоны пульса сохраняет ширину зоны. Всё остальное
   в «Дополнительно» и меняется на паузе без завершения тренировки.

Логика лежит в `Shared/CadenceController.swift` и `Shared/RegulatorEngine.swift`
и покрыта тестами.

## Предел и подсказки в наушники

Если ритм уже стоит на нижней границе, а пульс выше цели дольше десяти
секунд, снижать ритм больше нечего: нужно сбавлять усилие. В этом состоянии
щелчок становится глуше и ниже, каждый четвёртый такт звучит двойным ударом,
и голос говорит «сбавь». Когда пульс вернулся под цель с запасом в два удара,
щелчок возвращается к обычному и звучит «в норме». Голос можно выключить,
задать повтор «сбавь» раз в N секунд и громкость. Логика в
`Shared/RegulatorEngine.swift` (`isOverLimit`), звук в `SharedAudio/`.

## Метрики и отчёт

- Ритм метронома подписан как BPM, рядом фактический каденс с шагомера (SPM).
- На часах: контакт с землёй, вертикальные колебания и эффективность
  (метров на удар сердца за последние 100 м) на главной странице; темп,
  средний темп, дистанция и время на второй странице.
- После остановки показывается отчёт: дистанция, время, средний темп,
  средний пульс, средний каденс, средний ритм, эффективность, контакт
  с землёй, колебания. Итоги хранятся на устройстве, с часов пересылаются
  на телефон и видны в «Истории».
- Тренировка с часов сохраняется в Здоровье с маршрутом, скоростью,
  мощностью, длиной шага, контактом и колебаниями: для этого запрашивается
  разрешение на запись этих типов, без него HealthKit молча отбрасывает метрики.

## Сборка

Проект описан в `project.yml`, файл `.xcodeproj` генерируется:

```bash
brew install xcodegen
xcodegen generate
open InnerPace.xcodeproj
```

Тесты логики выполняются на macOS, без симулятора:

```bash
xcodebuild test -project InnerPace.xcodeproj -scheme SharedLogicTests -destination 'platform=macOS'
```

## Первый запуск на устройстве

1. В Xcode выберите схему `InnerPace` и подключённый iPhone.
2. Команда разработчика уже прописана в `project.yml` (`DEVELOPMENT_TEAM`).
   Если Xcode попросит, включите автоматическую подпись в обоих таргетах.
3. Запустите приложение, разрешите Bluetooth. Наденьте Polar H10 и нажмите
   «Подключить». Датчик запоминается и в следующий раз подключается сам.
4. Для часов включите на них режим разработчика (Настройки, Конфиденциальность
   и безопасность), затем в Xcode выберите схему `InnerPaceWatch`
   и устройство «Apple Watch via iPhone». Первый Run зарегистрирует часы
   в профиле подписи. При запуске на часах разрешите Здоровье и геопозицию.

## Структура

- `Shared/` логика без зависимостей от UI: настройки, сглаживание, регулятор, общий цикл подстройки.
- `SharedAudio/` метроном, общий для телефона и часов.
- `iOS/` приложение для телефона: Bluetooth, экраны.
- `Watch/` приложение для часов: тренировка HealthKit, маршрут, экраны.
- `Design/` исходник иконки и скрипт её рендера.
- `Tests/` тесты логики регулятора, фильтра и настроек.
